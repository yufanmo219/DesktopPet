# 钓鱼 QA 跳关工具

双击 `QA跳到下一个新鱼关卡.command` 即可使用。

它会先只读显示：

- 当前关卡；
- 将按正常通关结算的关卡区间；
- 下一条新鱼出现的关卡和鱼名；
- 累加到现有 XP 的准确数值。

只有输入 `y` 确认后才会修改存档。写入前会在正式存档旁边创建
`desktop_pet_save.qa_before_level_skip_时间戳.json` 备份。

## 规则

- 关卡生成、目标、难度和 XP 表完全不变；工具直接读取现有
  `FishingLevelCatalog`。
- 当前关卡到下一条新鱼关卡的前一关，逐关累加原有 `xp_reward`。
- 下一条新鱼出现的关卡不会自动结算，由 QA 亲自游玩。
- 跳关视同当前尝试成功，因此清除该关的临时重试加成。
- 不修改鱼图鉴、鱼缸、爱心、猫、商店和其他游戏进度。
- 第 449 关以后没有更多新鱼；此时工具只提示，不修改存档。

运行前请关闭 Desktop Pet，防止仍在运行的游戏用内存中的旧进度覆盖存档。

## QA 后删除

游戏没有引用本目录。QA 完成后直接删除整个
`qa_tools/fishing_level_skipper` 目录即可移除程序，不需要改
`project.godot`、场景或正式游戏代码。存档旁的安全备份可以在确认进度后单独删除。
